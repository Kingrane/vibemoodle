# мехмат.edu

Красивый клиент учебных курсов мехмата ЮФУ (Moodle `edu.mmcs.sfedu.ru`):
дедлайны, материалы, оценки, прогресс и каталог курсов с записью в одном месте.
Материалы открываются внутри приложения, свои задания можно сдавать файлами и
онлайн-текстом. Своего сервера нет — браузер обращается к официальному API
Moodle напрямую.

## Стек

React 19 · Vite · TypeScript · Tailwind 4 · TanStack Query · React Router ·
Zustand · lucide-react

## Запуск

```powershell
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка
```
